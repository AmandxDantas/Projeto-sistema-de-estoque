# 📦 Sistema de Controle de Estoque em Python

## 📌 Sobre o projeto

Este projeto consiste em um sistema de controle de estoque desenvolvido em Python, com o objetivo de auxiliar no gerenciamento de produtos, controle de quantidades e movimentações de entrada e saída.

A aplicação foi criada para praticar conceitos de programação, organização de código, Programação Orientada a Objetos (POO) e banco de dados.

## 🚀 Funcionalidades

✅ Cadastro de produtos  
✅ Consulta de produtos cadastrados  
✅ Atualização de informações  
✅ Remoção de produtos  
✅ Entrada de estoque  
✅ Saída de estoque  
✅ Controle da quantidade disponível  
✅ Armazenamento de dados em banco de dados SQLite  

## 🛠️ Tecnologias utilizadas

- Python 3
- SQLite
- Programação Orientada a Objetos (POO)
- Git e GitHub
