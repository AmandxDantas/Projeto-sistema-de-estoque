# 📦 Sistema de Controle de Estoque Pro - Python

## 📌 Sobre o projeto

O **Sistema de Controle de Estoque Pro** é uma aplicação desenvolvida em Python para gerenciamento de produtos e movimentações de estoque.

O objetivo do projeto é simular uma solução utilizada em empresas para controle de mercadorias, permitindo cadastrar produtos, acompanhar entradas e saídas, consultar informações e gerar análises do estoque.

O projeto foi desenvolvido aplicando conceitos de **Programação Orientada a Objetos (POO)**, estruturas de dados e lógica de programação.

---

## 🚀 Funcionalidades

### 📋 Cadastro de produtos
- Adicionar novos produtos
- Gerar código de identificação
- Definir nome, categoria, preço e quantidade

### 📦 Controle de estoque
- Registrar entrada de produtos
- Registrar saída de produtos
- Atualizar quantidade automaticamente
- Verificar disponibilidade em estoque

### 🔎 Consultas
- Listar todos os produtos
- Buscar produto pelo código ou nome
- Visualizar informações detalhadas

### 📊 Relatórios
- Mostrar produtos com baixo estoque
- Calcular valor total do estoque
- Exibir histórico de movimentações
